# 📱 Пульт управления Claude Code с телефона — чек-лист настройки

Управление проектами **IELTS Prep · Partyum UZB · Personal Brand AI · SubTrack** из одного места (телефон / телеграм), как у Дымшакова.

Стек: **Claude Code on the web** (дашборд сессий) + **Remote Control** (файлы на твоём компе) + **Telegram Channels** (доставка результатов) + **Voice** (диктовка).

Иди по блокам сверху вниз. Блоки 1–4 — база. Блок 5 — голосовуха. Блок 6 — паттерн диспетчер/дашборд.

---

## Блок 0. Подготовка (один раз)

- [ ] Подписка **Pro / Max / Team** на claude.ai (Remote Control и web без неё не работают)
- [ ] На десктопе установлен Claude Code CLI и ты залогинен: `claude` → вход через claude.ai (не API-ключ)
- [ ] Установлен **Bun** (нужен для телеграм-плагина): `curl -fsSL https://bun.sh/install | bash`
- [ ] Установлен **tmux** (чтобы сессии не умирали при закрытии терминала): `brew install tmux` (mac) / `apt install tmux` (linux)
- [ ] Мобильное приложение «Claude by Anthropic» стоит на телефоне (iOS/Android). Внутри CLI: `/mobile` покажет QR для установки/входа

---

## Блок 1. Дашборд сессий (облако) — claude.ai/code

Это встроенный дашборд из твоего скриншота. Задача = отдельная сессия + отдельная ветка.

- [ ] Каждый из 4 проектов лежит в **своём GitHub-репозитории**:
  - [ ] `______/ielts-prep`
  - [ ] `______/partyum-uzb`
  - [ ] `______/personal-brand-ai`
  - [ ] `______/subtrack`
- [ ] Установлен **Claude GitHub App** (claude.ai/code предложит при первом подключении репы)
- [ ] Создано облачное окружение: claude.ai/code → создать environment (имя, network = `Trusted` по умолчанию, env-переменные, опц. bash-скрипт для сетапа)
- [ ] Из терминала синхронизирован доступ: `/web-setup` внутри Claude Code (подтянет gh-токен, создаст дефолтное окружение)
- [ ] Проверка: открой claude.ai/code с телефона → видишь список сессий с вкладками `Needs Input / Ready for review / Working`
- [ ] Включены **пуш-уведомления**: `/config` → уведомления о `needs-input` / `done`

### Закладки быстрого запуска (по одной на проект)

Сохрани на телефоне 4 закладки — тап открывает сессию с уже вписанной репой:

- [ ] IELTS: `https://claude.ai/code?repositories=______/ielts-prep`
- [ ] Partyum: `https://claude.ai/code?repositories=______/partyum-uzb`
- [ ] Brand AI: `https://claude.ai/code?repositories=______/personal-brand-ai`
- [ ] SubTrack: `https://claude.ai/code?repositories=______/subtrack`

> Можно вписать и задачу сразу: `...?repositories=______/subtrack&prompt=Собери%20лендинг%20дня%203`

Док: https://code.claude.com/docs/en/web-quickstart

## Блок 2. Remote Control — Клод работает с файлами на твоём компе

Нужен, когда задача трогает локальные файлы, собирает лендинг локально или делает скриншоты запущенного приложения.

- [ ] На десктопе, внутри tmux, запусти сервер-режим (несколько сессий из одного процесса):
  ```bash
  tmux new -s claude
  claude remote-control --spawn worktree
  ```
- [ ] Появится URL сессии → нажми **пробел** для QR → отсканируй телефоном
- [ ] (Опц.) Включить Remote Control для всех сессий: `/config` → **Enable Remote Control for all sessions**
- [ ] Проверка: с телефона зашёл в сессию, дал задачу, Клод читает файлы с компа
- [ ] Проверка вложений: отправил боту/в сессию картинку с телефона → она скачалась на комп и подставилась как `@файл`

> `--spawn worktree` даёт каждой сессии свой git worktree — проекты не мешают друг другу. `--capacity N` — лимит сессий (по умолч. 32). Терпит разрыв сети ~10 мин.

Док: https://code.claude.com/docs/en/remote-control

## Блок 3. Telegram-бот — доставка результатов (скрины, лендинги, файлы)

Официальный плагин. Именно так результаты прилетают в телеграм.

- [ ] В телеге: **@BotFather** → `/newbot` → имя + юзернейм на `...bot` → скопируй токен `123456789:AAH...`
- [ ] В Claude Code: `/plugin install telegram@claude-plugins-official`
  - [ ] если маркетплейс не найден: `/plugin marketplace add anthropics/claude-plugins-official` затем повтори установку
- [ ] `/reload-plugins`
- [ ] `/telegram:configure 123456789:AAH...` (запишет `~/.claude/channels/telegram/.env`)
- [ ] Перезапусти с флагом канала (иначе бот не подключится):
  ```bash
  claude --channels plugin:telegram@claude-plugins-official
  ```
- [ ] Напиши боту в личку → он вернёт **6-значный код** → `/telegram:access pair <код>`
- [ ] Закрой от чужих: `/telegram:access policy allowlist`
- [ ] Проверка: попроси Клода прислать файл — он уходит в тг (картинки авто-превью, до 50 МБ)

> Ограничения официального плагина: нет истории/поиска сообщений и **нет транскрипции голосовых**. Если голосовухи критичны — Блок 5.

Док: https://code.claude.com/docs/en/channels · плагин: https://github.com/anthropics/claude-plugins-official/tree/main/external_plugins/telegram

## Блок 4. Голос (нативный)

- [ ] В сессии: `/voice` → **push-to-talk** (зажми пробел, говори, отпусти) или тап-переключение
- [ ] Работает и в dispatch/agent-view — можно диктовать фоновой сессии
- [ ] Альтернатива без настройки: диктовка клавиатуры телефона прямо в поле ввода claude.ai/code

Док: https://code.claude.com/docs/en/voice-dictation

## Блок 5. (Опционально) Сторонний бот с транскрипцией голосовых — 1-в-1 как у Дымшакова

Если хочешь «наговорил голосовуху боту на прогулке» + команду `/repo` для переключения между 4 проектами прямо в чате.

- [ ] Клонируй **RichardAtCT/claude-code-telegram**: https://github.com/RichardAtCT/claude-code-telegram
- [ ] `uv tool install` (Python 3.11+)
- [ ] Создай `.env`:
  - [ ] `TELEGRAM_BOT_TOKEN=` (токен от BotFather, отдельный бот)
  - [ ] `APPROVED_DIRECTORY=` → родительская папка со всеми 4 проектами
  - [ ] `ALLOWED_USERS=` → твой Telegram user id
  - [ ] движок транскрипции: Mistral Voxtral / OpenAI Whisper / локальный whisper.cpp
- [ ] Запусти под tmux/screen (или на маленьком VPS, чтобы был 24/7)
- [ ] Проверка: голосовуха боту → транскрибируется → Клод выполняет; `/repo` переключает проект

## Блок 6. Паттерн «Диспетчер-сессия» + «Дашборд-сессия»

Это приём организации (как в твоём списке сессий), а не кнопка. Он и даёт «рулю всем из одного места».

- [ ] **Диспетчер-сессия** — сессия, где ты не кодишь, а раздаёшь задачи голосом: «по IELTS — X, по SubTrack — Y». Она готовит/запускает рабочие сессии по нужным репам. Твоя точка входа.
  - [ ] Создай сессию, назови её `Диспетчер`
  - [ ] В её первом сообщении задай роль: «Ты диспетчер. Я даю задачи по проектам IELTS/Partyum/Brand AI/SubTrack — ты формулируешь их и запускаешь/готовишь под нужный репозиторий, а мне присылаешь короткое подтверждение в телеграм»
- [ ] **Дашборд-сессия** — собирает статус по всем проектам (ветки, PR, что готово к ревью / ждёт ввода) и шлёт сводку в тг.
  - [ ] Создай сессию, назови `Дашборд`
  - [ ] Повесь на расписание (**Routine**), напр. каждое утро → утренняя сводка в телеграм
